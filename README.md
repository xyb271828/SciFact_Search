# SciFact Search and Lesson Ranking

A reproducible Python search project with a from-scratch BM25 index, MiniLM/FAISS dense retrieval, reciprocal rank fusion (RRF), and a LightGBM LambdaMART reranker. The original [SciFact notebook](SciFact_Search.ipynb) retains the first BM25 experiment. The Python modules below run the larger evaluation and serve a fictional lesson catalog.

- **SciFact, 300 official test queries** — RRF improved NDCG@10 from **0.6829 to 0.7225** and Recall@100 from **0.9253 to 0.9550** relative to dev-tuned BM25. Paired ΔNDCG@10 was **+0.0397**, 95% CI **[+0.0157, +0.0624]**.
- **Synthetic lessons, 5,000 documents and 60 topic-held-out test queries** — LambdaMART improved NDCG@10 from **0.4988 to 0.7154** on the same RRF candidates. The grade-filtered lexical baseline scored **0.7121**, close to LambdaMART. [Full results and trade-offs](reports/W01_Search_Report.md)

## Reproduce

Use Python 3.11 or 3.12. The first dense run downloads the pinned public MiniLM ONNX weights (about 87 MB) and precomputes embeddings. Later runs reuse the local cache.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python -m pytest -q
search-lab benchmark --dataset scifact --output runs/scifact.json
search-lab benchmark --dataset lessons --output runs/lessons.json
python -m search.probes
```

Add `--lexical-only` to evaluate BM25 without initializing MiniLM. The benchmark outputs include per-query scores, p50/p95/p99, paired bootstrap deltas, and the IDs and rank changes of example queries. The lessons run also saves the model and manifest expected by the API. Inspect the compact JSON for the measured runs in [reports/results](reports/results).

## Run locally

Start the service after the lesson benchmark. Set `SEARCH_DATA_DIR` and `SEARCH_ARTIFACT_DIR` to match the cache and output paths if you changed them.

```bash
uvicorn search.service:create_app --factory --host 127.0.0.1 --port 8000
```

```bash
curl -s http://127.0.0.1:8000/health
curl -s -H 'Content-Type: application/json' \
  -d '{"query":"Grade 5 beginner practice on equivalent fractions","k":3}' \
  http://127.0.0.1:8000/search
python -m search.load_test --qps 25 --requests 300
```

The request supports `mode` (`bm25`, `rrf`, or `lambdamart`) and `rerank_depth` (1–100). The response includes ranked lesson metadata and separate stage timings. The load test compares HTTP latency under one offered rate and reports achieved rates, errors, and dispatch delay. A [Dockerfile](Dockerfile) provides an alternative entry point. Mount the local cache and experiment artifacts after the lessons run.

```bash
docker build -t lesson-search .
docker run --rm -p 127.0.0.1:8000:8000 \
  -v "$PWD/.cache:/cache" -v "$PWD/runs:/runs:ro" lesson-search
```

## Independent LambdaMART benchmark

After obtaining [MSLR-WEB10K from Microsoft Research](https://www.microsoft.com/en-us/research/project/mslr/overview/) under its dataset agreement, point the runner at the extracted `Fold1` directory:

```bash
search-lab mslr --fold /path/to/Fold1 --output runs/mslr.json
```

The runner fits on `train.txt`, uses `vali.txt` for early stopping, and compares the final model with MSLR's precomputed title BM25 feature on `test.txt`. The loader and training path have a fixture check. A score on the official fold remains pending.

## Layout and inputs

- `search/` contains the retrieval pipeline, dataset adapters, benchmark, ranker, and local API.
- `discoverylib/` contains search and reusable ranking/CTR metrics.
- `tests/` contains scoring, fusion, group integrity, and data split checks.
- `reports/` contains the benchmark report, logging design, and benchmark output summaries.

The public benchmark uses [BEIR SciFact](https://github.com/beir-cellar/beir/wiki/Datasets-available) and [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). The lesson data is generated by `search/education.py` with seed 42. It includes no learner records, company files, or real traffic. Read the source terms before redistributing source datasets or model files.
